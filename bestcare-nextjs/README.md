# BestCare – Next.js oldal

    npm install
    npm run dev      # http://localhost:3000

Az űrlap e-mailes kiküldéséhez másold a `.env.example`-t `.env.local`-ra és töltsd ki. Nélküle az érdeklődés a szerver konzoljára kerül.
Az árak és elérhetőségek helyőrzők: `app/arlista/page.js`, `components/Footer.js`.
